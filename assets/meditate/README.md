# Meditate scenery and sound wheels

The Scenery button opens nine themes: starry lake, alpine dusk, firefly forest, seaside, misty forest, rainy lake, waterfall, forest canopy, and starry peaks. Desert has been removed. The former Aurora, Wildflower sky, and Moonlit artwork files have been deleted and replaced with three real Unsplash photographs by John Towner, Geran de Klerk, and Daniel Leone. Original photo IDs, photographer names, unedited JPEG hashes, and the pinned GitHub collection used for acquisition are recorded in `scenes/sources.json`. The collection preserves the photographer and Unsplash photo ID in each filename; photos were copied without resizing, recoloring, or generated additions. Direct stock-library requests were blocked in this environment, so these files were acquired from that accessible collection rather than downloaded directly from Unsplash. The firefly scene overlays animated points on a sourced forest photograph; it is not presented as a firefly photograph.

The Audio button opens nine corresponding animated cards: rain, ocean waves, stream, forest birds, wind, white noise, pink noise, summer night, and fireplace. Choosing a sound only prepares that recording and previews its GIF inside the sound wheel; it never starts playback. Changing scenery or sound stops an active session, so the next session always requires an explicit Start click. The floating playback/volume panel has been removed. The existing Start/End meditation button starts or stops the chosen recording; before a sound is chosen, Start opens the sound wheel. Use device volume controls for loudness. The Sound credits link has been removed from the application interface; recording attribution and license files remain in the repository. Leaving Meditate pauses playback. Initial page load never plays audio. Playback errors are announced to assistive technology; Start retries playback.

Both wheels use the same upright, spring-driven, infinite looping interaction, supporting drag, click, scroll and keyboard navigation. Opening one closes the other. Repeated taps on the same left-side icon keep its wheel open; they do not toggle it closed. Escape, outside clicks and leaving the tab close the wheel. The Start/End button remains usable after outside-click dismissal.

All photos, animated images and audio are local assets. `sound-art/SOURCES.md` distinguishes the original animated SVG effects and fireplace SVG effects. `sounds/SOUNDS_LICENSING.md`, `sounds/sources.json` and `sounds/credits.html` retain the recording authors, sources and licenses. Audio is AAC for phone compatibility, using up to 40 seconds of each source and a one-second tail/head crossfade before encoding. HTML audio loop timing still depends on the device.

`scene-picker.js` and `scene-picker.css` are embedded in both main HTML entry pages; synchronize these copies. Current-instance Chromium mobile validation covers all nine remaining scenery changes, real sound playback, Start/End, tab cleanup, absence of the volume popup and credits link, manual Start after sound selection, and hiding every sound image after Start on both main entries. Canvas pixel comparisons confirm the white-noise poster remains unchanged before selection. All nine sound previews and actual recordings were also checked, along with stopping on scenery changes and reduced-motion previews. Headless validation cannot substitute for listening to audio output or testing real iOS Safari.

Sound cards use real looping `.gif` files rendered locally from the existing SVG source artwork: 320×180, 60 frames at 10 fps, six-second loops. SVG source and `.still.svg` posters remain available for editing and reduced-motion/idle display. Closed wheels and offscreen cards use still posters. While the wheel is open, visible non-white-noise cards animate without selection; white noise stays static until selected. Reduced-motion mode uses still posters until the user explicitly selects a sound; that selected card plays its GIF while visible. Closing the wheel or moving the card offscreen restores its still poster. There is no separate enlarged sound preview. Clicking Start closes both wheels and removes all sound images from view, leaving only the chosen scenery and playback controls. Animation is visual only and never starts audio. Both main entries were checked with mobile touch input, actual GIF screenshot-frame differences, white-noise gating, and selecting a sound then directly tapping Start. Real iOS Safari remains unverified.

Start now opens a bottom duration sheet before playback. Choose 1–120 minutes in one-minute steps (default 20), then press Begin. Without a prior sound selection, Rain is used. A wall-clock deadline stops audio when the duration ends; visibility changes recheck the deadline. Escape, backdrop and close dismiss the sheet; keyboard focus is contained and restored. Duration bubble follows the native touch/keyboard slider and lifts while dragging; reduced motion shortens transitions. Reference-video position and motion fidelity have not been verified.

The duration sheet now follows the supplied 474995731.mp4 reference: centered fixed pointer, draggable vertical minute ticks, inertial release and spring snapping, with the selected minutes above. It uses a translucent backdrop-blurred glass surface. It supports 1–120 minutes, keyboard arrows/Home/End/PageUp/PageDown, wheel and touch, reduced motion, and closing cleanup. Typography is unified through assets/typography.css, embedded in both entries and standalone previews, including scenery/sound captions. SF Pro is resolved locally on Apple devices or where installed; other platforms use system fallback. No SF font binaries are redistributed. Existing vector-outlined artwork text cannot be restyled through CSS.
