# Meditate scenery and sound wheels

The Scenery button opens nine themes: starry lake, aurora, firefly forest, seaside, misty forest, rainy lake, waterfall, wildflower sky, and moonlit landscape. The blurry desert image has been removed. Replacement photographs for the illustrated/non-natural scenes remain pending access to stock-photo sources; do not describe them as replaced yet. Artwork sources and processing details are in `scenes/sources.json`. Aurora and moon imagery are sourced illustrations. The firefly scene overlays animated points on a sourced forest photograph; it is not presented as a firefly photograph.

The Audio button opens nine corresponding animated cards: rain, ocean waves, stream, forest birds, wind, white noise, pink noise, summer night, and fireplace. Choosing a sound only prepares that recording and previews its animation; it never starts playback. Changing scenery or sound stops an active session, so the next session always requires an explicit Start click. The floating playback/volume panel has been removed. The existing Start/End meditation button starts or stops the chosen recording; before a sound is chosen, Start opens the sound wheel. Use device volume controls for loudness. The Sound credits link has been removed from the application interface; recording attribution and license files remain in the repository. Leaving Meditate pauses playback. Initial page load never plays audio. Playback errors are announced to assistive technology; Start retries playback.

Both wheels use the same upright, spring-driven, infinite looping interaction, supporting drag, click, scroll and keyboard navigation. Opening one closes the other. Escape, outside clicks and leaving the tab close the wheel. The Start/End button remains usable after outside-click dismissal.

All photos, animated images and audio are local assets. `sound-art/SOURCES.md` distinguishes the original animated SVG effects and fireplace SVG effects. `sounds/SOUNDS_LICENSING.md`, `sounds/sources.json` and `sounds/credits.html` retain the recording authors, sources and licenses. Audio is AAC for phone compatibility, using up to 40 seconds of each source and a one-second tail/head crossfade before encoding. HTML audio loop timing still depends on the device.

`scene-picker.js` and `scene-picker.css` are embedded in both main HTML entry pages; synchronize these copies. Current-instance Chromium mobile validation covers all nine remaining scenery changes, real sound playback, Start/End, tab cleanup, absence of the volume popup and credits link, manual Start after sound selection, and persistent selected animation previews on both main entries. Canvas pixel comparisons confirm the white-noise poster remains unchanged before selection. All nine sound previews and actual recordings were also checked, along with stopping on scenery changes and reduced-motion previews. Headless validation cannot substitute for listening to audio output or testing real iOS Safari.

Sound card SVGs have separate `.still.svg` posters. Unselected cards and closed wheels always use posters; only the selected card in an open wheel loads its animated SVG. Reduced-motion mode keeps the still poster even when selected. After closing a wheel, the selected sound has its own persistent animated preview above Start/End, so the animation remains visible without reopening the sound list. The preview does not imply audio is playing.
