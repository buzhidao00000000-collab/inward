# Meditate scenery and sound wheels

The Scenery button opens nine themes: starry lake, alpine dusk, firefly forest, seaside, misty forest, rainy lake, waterfall, forest canopy, and starry peaks. Desert has been removed. The former Aurora, Wildflower sky, and Moonlit artwork files have been deleted and replaced with three real Unsplash photographs by John Towner, Geran de Klerk, and Daniel Leone. Original photo IDs, photographer names, unedited JPEG hashes, and the pinned GitHub collection used for acquisition are recorded in `scenes/sources.json`. The collection preserves the photographer and Unsplash photo ID in each filename; photos were copied without resizing, recoloring, or generated additions. Direct stock-library requests were blocked in this environment, so these files were acquired from that accessible collection rather than downloaded directly from Unsplash. The firefly scene overlays animated points on a sourced forest photograph; it is not presented as a firefly photograph.

The Audio button opens nine corresponding animated cards: rain, ocean waves, stream, forest birds, wind, white noise, pink noise, summer night, and fireplace. Choosing a sound only prepares that recording and previews its animation; it never starts playback. Changing scenery or sound stops an active session, so the next session always requires an explicit Start click. The floating playback/volume panel has been removed. The existing Start/End meditation button starts or stops the chosen recording; before a sound is chosen, Start opens the sound wheel. Use device volume controls for loudness. The Sound credits link has been removed from the application interface; recording attribution and license files remain in the repository. Leaving Meditate pauses playback. Initial page load never plays audio. Playback errors are announced to assistive technology; Start retries playback.

Both wheels use the same upright, spring-driven, infinite looping interaction, supporting drag, click, scroll and keyboard navigation. Opening one closes the other. Repeated taps on the same left-side icon keep its wheel open; they do not toggle it closed. Escape, outside clicks and leaving the tab close the wheel. The Start/End button remains usable after outside-click dismissal.

All photos, animated images and audio are local assets. `sound-art/SOURCES.md` distinguishes the original animated SVG effects and fireplace SVG effects. `sounds/SOUNDS_LICENSING.md`, `sounds/sources.json` and `sounds/credits.html` retain the recording authors, sources and licenses. Audio is AAC for phone compatibility, using up to 40 seconds of each source and a one-second tail/head crossfade before encoding. HTML audio loop timing still depends on the device.

`scene-picker.js` and `scene-picker.css` are embedded in both main HTML entry pages; synchronize these copies. Current-instance Chromium mobile validation covers all nine remaining scenery changes, real sound playback, Start/End, tab cleanup, absence of the volume popup and credits link, manual Start after sound selection, and persistent selected animation previews on both main entries. Canvas pixel comparisons confirm the white-noise poster remains unchanged before selection. All nine sound previews and actual recordings were also checked, along with stopping on scenery changes and reduced-motion previews. Headless validation cannot substitute for listening to audio output or testing real iOS Safari.

Sound card SVGs have separate `.still.svg` posters. Closed wheels and offscreen cards use still posters. While the sound wheel is open, visible non-white-noise cards animate without requiring selection, so the list previews the animations immediately. White noise alone stays static until selected. Reduced-motion mode uses the still posters. After closing a wheel, the selected sound has its own persistent preview above Start/End; opening a wheel shows its animated cards in place of that duplicate preview. Animation is visual only and never starts the audio. Mobile Chromium touch validation checks repeated icon taps, all nine scenery choices, actual screenshot-frame differences for the rain card and persistent preview, white-noise gating, and manual Start/End on both main entries. Real iOS Safari remains unverified.
